Cloush Application Form Web Component

Easily embed the Cloush application form on any website with a simple HTML tag.

<!-- Basic Usage -->
<script type="module" src="https://cdn.cloush.com/components/application-form/latest/web.esm.js"></script>
<script nomodule src="https://cdn.cloush.com/components/application-form/latest/web.js"></script>

<application-form

  type="candidate"
  job-id="job123">
</application-form>

<!-- Usage with Callbacks -->
<script type="module" src="https://cdn.cloush.com/components/application-form/latest/web.esm.js"></script>
<script nomodule src="https://cdn.cloush.com/components/application-form/latest/web.js"></script>

<script>
  function handleApplicationSuccess() {
    document.getElementById('success-message').style.display = 'block';
    console.log('Application submitted successfully!');
  }
  
  function handleReferFriend() {
    window.open('https://example.com/refer', '_blank');
    console.log('Referring a friend...');
  }
</script>

<application-form
  title="Apply Now"
  type="candidate"
  job-id="job789"
  company-data='{"id": "company789", "name": "Tech Innovators"}'
  on-success="handleApplicationSuccess"
  on-refer-friend="handleReferFriend">
</application-form>

<div id="success-message" class="success-message">
  Thank you for your application! We'll be in touch soon.
</div>

Installation

To use the Cloush Application Form web component on your website, add the following script tags to your HTML page:

<script type="module" src="https://cdn.cloush.com/components/application-form/latest/web.esm.js"></script>
<script nomodule src="https://cdn.cloush.com/components/application-form/latest/web.js"></script>

Then you can use the <application-form> element anywhere in your HTML.

API Documentation

Properties

  • title: The title displayed at the top of the form
  • type: The type of application (candidate or employee)
  • job-id: The ID of the job being applied for
  • company-data: JSON string containing company information
  • custom-fields: JSON array of custom fields to include
  • exclude-fields: JSON array of fields to exclude
  • on-success: Function name to call when application is successful
  • on-refer-friend: Function name to call when refer friend is clicked
  • script-url: Optional URL to load custom scripts
  • style-url: Optional URL to load custom styles
